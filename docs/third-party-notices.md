# Third-party notices

## Domain icons (the web UI)
The brand marks in `ui/src/lib/icons/brands.ts` come from two packs. [Simple Icons](https://github.com/simple-icons/simple-icons) 16.38.0 is the first choice; it is released under the CC0 1.0 Universal public domain dedication. For the marks Simple Icons has dropped (Microsoft, Amazon, LinkedIn, Slack, OpenAI, and a few more) the glyphs come from [Bootstrap Icons](https://icons.getbootstrap.com) 1.13.2, released under the MIT licence below, given a brand colour by hand. Simple Icons asks everyone who uses its marks to read its disclaimer: the marks are trademarks or logos of their owners, and are shown here only to identify the name they belong to. WrenDNS is not affiliated with or endorsed by any of them.

The glyph data and the map from domains to brands are generated by `ui/scripts/brand-icons.mjs` and committed, so a build never fetches anything (the path data is minified with [svgo](https://github.com/svg/svgo) 4.1.0, MIT, while it is generated; svgo is not shipped). To add a brand or move to another release of either pack, change the list or the pinned version in that script and run it (the comment at its top says how, and the developer page [Extend the domain icons](https://wrendns.com/dev-icons.html) has the whole recipe), then review the diff.

## Content-category lists (downloaded, never bundled)

The content categories (FLT-901, `presets/categories/*.toml`) name lists that a node downloads from their maintainers while a group uses them. WrenDNS does not ship, copy or redistribute any of them: the binary and the image carry only the catalog (names, URLs, licences, sizes), and a list is fetched by your node, from the maintainer's own host, when you turn a category on. Their licences therefore do not apply to WrenDNS's own, and no HaGeZi, StevenBlack, Perflyst or Bon-Appetit code is used (AGENTS.md rule 6). The Categories view shows each source's maintainer, licence and a link, and this page lists them.

| Source | Maintainer | Licence | Used for |
|---|---|---|---|
| [`hagezi/dns-blocklists`](https://github.com/hagezi/dns-blocklists) | HaGeZi | GPL-3.0 | adult content, gambling, piracy, social networks, fake stores, DoH, VPN and proxy bypass, dynamic DNS, URL shorteners, hosting, risky TLDs, pop-up ads, the threat-intelligence feeds (malware, phishing, scam), the ad block tiers, and the per-vendor native trackers |
| [`hagezi/nrd`](https://github.com/hagezi/nrd) | HaGeZi | GPL-3.0 | newly registered domains and DGA-like new domains, 7 days. HaGeZi publishes them as-is, with no guarantees |
| [`StevenBlack/hosts`](https://github.com/StevenBlack/hosts) | Steven Black | MIT | the fake-news list |

The GPL-3.0 of HaGeZi's lists covers the lists as data that your node fetches; the question whether a GPL-3.0 dataset fetched at runtime needs anything more is recorded in ADR-995 as a risk for the owner, not resolved by legal review.

### blocklist.packettale.com (an aggregate, downloaded by your node)

The last group of the Categories view offers five categories from [blocklist.packettale.com](https://blocklist.packettale.com/) (code at [`packettale/dns-blocklist`](https://github.com/packettale/dns-blocklist), MIT). The site is an aggregator: it republishes other maintainers' lists as plain domain feeds and says "Upstream data retains its original terms" ([NOTICE](https://blocklist.packettale.com/NOTICE.md), [sources](https://blocklist.packettale.com/sources.md)); some of its upstreams are GPL-3.0 or non-commercial, and none of those is offered here. As with the lists above, WrenDNS does not ship, copy or redistribute these feeds: the binary and the image carry only the catalog entry (name, URL, licence, size), and your node downloads the feed from blocklist.packettale.com once a day when you turn the category on. Each one is off by default. The site's own table gives only generic terms for these upstreams ("Original upstream license and embedded attribution apply", "See upstream repository"), so the licences below were read at each upstream repository on 2026-11-25.

## IP geolocation data (the world view)
The world view's optional country database is **IP to Country Lite** by [DB-IP.com](https://db-ip.com), published under the [Creative Commons Attribution 4.0 International licence (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). WrenDNS **does not ship or redistribute it**: an admin turns it on in Settings, and each node then downloads the current monthly file from the publisher (or from a mirror the admin names) and builds its own compact copy in its data directory. The licence asks for attribution, which the Settings card, the world view's footer and this page give: *IP geolocation by DB-IP.com*. DB-IP's terms are re-checked at each release.

## World map data (the web UI)
The land and the country points in `ui/src/lib/world-data.ts` are generated by `ui/scripts/gen-world-data.py` from [Natural Earth](https://www.naturalearthdata.com) 1:110m admin-0 countries (public domain) and from the tz database's `iso3166.tab` and `zone.tab` (public domain) for names and the small states' points. They are committed, so a build never fetches anything, and the world view loads no tiles, fonts or scripts from outside.

## Fonts (the web UI and the project site)

The web UI and the project site set their text in **Figtree** and their code, domains and addresses in **IBM Plex Mono** (the brand's type, `brand/README.md`). Both are under the SIL Open Font License 1.1, which allows bundling and redistribution with software when the licence and copyright notices travel with them.
