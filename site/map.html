Observability first

See your network, and who is having a bad day

Monitor → Network map draws your gateway, networks and VLANs, devices, WrenDNS nodes and upstreams, joined by the flows between them. Moving dashes show how busy each flow is, and every node says how it is doing in a shape, a word and a colour, so a device that is failing lookups stands out at a glance. Select it for the reasons, then jump to its queries, Explain or anomalies.

The map never slows DNS. It is built on the aggregator thread from a bounded sample of lookups, never in the path that answers a query, and it never shows a domain name.

How to read it

States

A circle with a check is OK, a triangle is Warning, an octagon with a cross is Failing, and a dashed circle is Idle: too few answers in the last minute to say. Colour is never the only sign.

Flows

One dash per half a query a second, wider as the rate grows. Motion stops when the tab is hidden and, for good, under your system's reduce-motion setting; a Table view shows the same data as text.

Filters

Network, group, node, state and a device's name or address, kept in the page's address so a view can be linked.

Sampling and its error

Each node samples up to event_rate lookups a second (10 to 2,000, default 200). Above that it keeps every Nth lookup and counts each for N, and the page says Sampled, 1 in N. A flow with 20 sampled answers is read to within roughly a fifth; with 400, within about 5%. Something is coloured only after min_sample real answers (default 20); until then it is Idle, never green.

Thresholds

In Settings → Query handling → Network map, an operator sets the sampling rate and when a flow turns Warning or Failing. While you type, a sentence says how the current map would change, and the form refuses a value out of range by name.

SettingDefaultTurnsWhen
warn_slow_pct10Warningthis share of answers are slower than warn_latency_ms (default: the latency objective)
warn_error_pct5Warningthis share are SERVFAIL or time out
error_pct25Failingthis share are SERVFAIL or time out (at least warn_error_pct)
warn_blocked_pct60Warningthis share of a device's answers are blocked (devices only)

The thresholds change only what the map shows, never an answer or an alert. An open breaker, an unreachable node, a rate-limited device and an open anomaly colour the map too. Also available as PUT /api/v1/map-settings/default and the agent tool plan_set_map.

Privacy and clusters

At query-log privacy level 0 and 1 devices are shown by address and name; at 2 they are hidden and one node stands for them; at 3 only network and resolver totals show. In a cluster every node samples its own lookups and the node you ask gathers the rest in the background, so a node that is down shows as unreachable and never delays the map.

GeoIP and its licence

The world view needs a country database, and it is off until an admin turns it on. It is DB-IP's "IP to Country Lite", published monthly under Creative Commons Attribution 4.0; each install downloads it from the publisher, nothing is bundled, and the credit "IP geolocation by DB-IP.com" appears with it. The download is checked for damage, not signed by the publisher. An admin turns it on in Settings, Query handling, GeoIP database, and the map is drawn in Monitor, World view. See the running guide for details.
